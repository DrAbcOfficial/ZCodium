ZCodium is blocked by macOS on first launch

Reason: the installer is not signed by ZCode, so Gatekeeper blocks the first launch.

Drag ZCodium into "Applications" first, then follow these steps:

1. Open Terminal: press Command + Space, type "Terminal", press Return.
2. Copy the entire command below, paste it into Terminal, press Return:

sudo /usr/bin/xattr -rd com.apple.quarantine "/Applications/ZCodium.app"

3. When Terminal asks for a password, type your login password. Nothing is shown on screen while typing — that is normal. Press Return when done.
4. Open ZCodium again.

Notes:
- The command uses the absolute path /usr/bin/xattr so another tool with the same name in your PATH (for example the Python xattr package) cannot shadow it and fail with "option -r not recognized".
- It only removes the quarantine flag (com.apple.quarantine) that macOS adds to downloaded files; it does not modify the app itself.
- If a future auto-update is blocked again, just run the command once more.

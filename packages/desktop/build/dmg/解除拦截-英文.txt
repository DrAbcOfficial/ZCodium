ZCodium is blocked by macOS on first launch

Reason: the installer is not code-signed or notarized by Apple, so Gatekeeper blocks the first launch.

After dragging ZCodium into "Applications", follow these steps:

1. Open Terminal: press Command + Space, type "Terminal", then press Return.
2. Copy the entire command below, paste it into Terminal, and press Return:

sudo xattr -rd com.apple.quarantine "/Applications/ZCodium.app"

3. When Terminal asks for a password, type your login password (nothing appears while typing), then press Return.
4. Open ZCodium again.

This command only removes the quarantine flag (com.apple.quarantine) that macOS adds to downloaded files; it does not modify the app itself.
If a future update is blocked again, just run the command once more.

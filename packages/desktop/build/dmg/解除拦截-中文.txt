ZCodium 首次打开被 macOS 拦截怎么办？

原因：安装包没有使用 Apple 的代码签名和公证，macOS 的 Gatekeeper 会拦截首次打开。

把 ZCodium 拖进「应用程序」后，按以下步骤解除拦截：

1. 打开「终端」（Terminal）：按 Command + 空格，输入“终端”，按回车。
2. 复制下面这一整行命令，粘贴到终端窗口，按回车：

sudo xattr -rd com.apple.quarantine "/Applications/ZCodium.app"

3. 终端提示输入密码时，输入你的开机密码（输入时不会显示任何字符），按回车。
4. 重新打开 ZCodium 即可。

这条命令只是移除 macOS 给下载文件添加的隔离标记（com.apple.quarantine），不会修改应用本身。
如果以后自动更新后又被拦截，重新执行一次即可。
